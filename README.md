# 🎵 自建私人 Web 音乐库｜PHP 轻量化本地音乐播放器

厌倦各大音乐平台会员限制、广告打扰？搭建属于自己的私有音乐站点，把收藏的本地音乐全部搬到网页端，电脑、手机浏览器随时随地收听你的专属曲库。

## ✨ 项目介绍

这是一套基于 PHP + 原生 JS 开发的**自托管本地音乐网页播放器**，不需要数据库，使用 JSON 文件存储配置与歌曲元数据，部署简单，上传文件即可使用。音频直接读取服务器`audio`文件夹，支持无损格式，自动识别同名封面图片，自带管理后台，界面现代玻璃拟态 UI，移动端自适应，打造完全属于你的私人音乐空间。

## 🚀 核心功能

### 🎧 前台播放功能

1. **全功能网页播放器**
HTML5 Audio 音频播放，支持播放 / 暂停、上一首、下一首、自动连播、进度拖拽调节、音量控制。内置**五段均衡器**，可以调节高低频音效，实现个性化听感。
2. **智能内容展示**
   - 每日专属推荐：根据日期种子自动生成每日 10 首随机推荐歌单，同一天推荐固定不变。
   - 按音乐风格自动分组展示卡片（流行、国风、粤语、摇滚、民谣、说唱、轻音乐、影视原声等）。
   - 完整歌曲列表视图，显示歌曲标签风格；自动读取同文件名图片作为歌曲封面，无封面自动生成首字符占位图。
3. **实时搜索过滤**：输入歌名 / 歌手，快速筛选歌曲，卡片视图、列表视图同步过滤。
4. **响应式界面**：电脑、手机浏览器完美适配，玻璃拟态毛玻璃效果，动画过渡流畅。

### ⚙️ 后台管理系统（admin.php）

1. **账号密码登录**：密码 hash 加密，保护后台访问权限，支持退出登录。
2. **本地音乐库管理**
   - 自动扫描`audio`目录音频文件，识别格式、文件大小；
   - 手动设置每首歌曲的音乐风格分类；
   - 一键删除服务器上的音频文件；
   - **导出 TXT 歌单**，导出全部歌曲清单，包含歌名、歌手、分类、格式、文件大小。
3. **站点 & 主题自定义设置**
   - 修改网站名称、副标题信息；
   - 自定义主色调、辅助色；
   - 多种背景模式：深色、柔光渐变、极简纯白、纯色浅灰、自定义图片背景；
   - 调节背景遮罩透明度；
   - 开关特效：玻璃拟态、入场淡入动画、背景流动光斑；
4. **数据存储**：使用`songs.json`保存歌曲元数据，`settings.json`保存主题配置，无需 MySQL 数据库。

### 📂 文件支持

音频格式：`mp3、m4a、wav、ogg、flac`无损音频均可识别；
封面图片：同文件名`jpg/png/webp`，放入 audio 文件夹自动匹配歌曲封面。

## 📋 部署要求

- PHP 环境（PHP7.4 及以上，开启 session 支持），Nginx/Apache 均可；
- 无需 MySQL 数据库；
- 文件目录权限：服务器需要对项目目录读写权限，用于生成 json 配置文件，读取 audio 音频文件夹。

## 📝 部署步骤

1. 将全部源码文件上传至 PHP 网站根目录；
2. 创建`audio`文件夹，把你的音乐文件、配套封面图片上传到此文件夹；
3. 访问 `admin.php` 进入后台登录，默认账号密码在`config.php`中可以修改；
4. 后台会自动扫描 audio 目录下所有音乐，设置歌曲分类；
5. 访问 `index.php` 即可进入音乐播放器前台页面开始听歌。

> 
> 提示：音频文件名建议不要使用特殊符号，同名图片和音频放在同一个 audio 目录即可自动识别封面。

## 🎨 界面特点

- 深色为主的现代 UI，支持多种主题配色与背景图片自定义；
- 卡片横向滚动歌单 + 完整歌曲列表双模式浏览；
- 毛玻璃玻璃拟态效果，可在后台一键开关；
- 无多余广告，纯净私人音乐体验。

## 📁 主要文件说明

表格

| 文件 | 用途 |
| --- | --- |
| index.php | 音乐播放器前台主页 |
| admin.php | 后台管理页面，登录、歌曲管理、主题设置 |
| config.php | 全局配置、常量定义、核心函数 |
| songs.json | 歌曲元数据存储文件，自动生成 |
| settings.json | 网站主题配置存储文件，自动生成 |
| audio/ | 存放音频与封面图片文件夹 |

## 💡 小提示

1. 修改管理员账号密码：打开`config.php`，修改`ADMIN_USER`账号，`ADMIN_PASS`使用`password_hash()`生成新密码；
2. 如果歌曲不显示：检查 audio 文件夹权限，确认音频后缀在支持格式列表；
3. 更换背景图：后台主题设置选择「自定义图片」，填入图片 URL，调节遮罩透明度；
4. 导出歌单：后台本地音乐页面，点击导出 TXT，保存完整音乐清单。
